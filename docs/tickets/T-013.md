# T-013 — Privacy: consent checkbox, 90-day retention, user deletion

**Depends on:** T-001, T-002, T-003
**Source:** TRD FR-07, TRD NFR-03, RA 10173

**Acceptance criteria:**
- Given every post, a consent checkbox ("I consent to Anthrix storing my name, photo, and contact for item matching.") is required; unchecked blocks submission.
- Given a privacy notice link at the footer, clicking it opens the RA 10173 privacy notice.
- Given an item older than 90 days, the item record and photos are auto-deleted (soft-delete with deleted_at, then hard purge per retention schedule).
- Given a user requests deletion, their item records and photos are deleted and a confirmation is shown.
- Given no health information is collected, any attempt to store health data is rejected at validation.

**Definition of done:** Consent required on all posts; privacy notice accessible; 90-day auto-deletion; user deletion request honored; no health data stored.
