# T-001 — Repo & stack setup

**Depends on:** none
**Source:** TRD §1 Overview, TRD §4 Data model

**Acceptance criteria:**
- Given a clean checkout, running the documented setup command produces a runnable dev server on localhost.
- Given the stack decision (SQLite single-file or managed Postgres), the database connects and migrations run without error.
- Given a `git status`, no uncommitted secrets or credentials are present.

**Definition of done:** Dev server responds; database migrations apply cleanly; `.env.example` present with no real secrets.
