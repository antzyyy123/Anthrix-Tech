# T-012 — Immutable audit log

**Depends on:** T-001, T-002
**Source:** TRD FR-08, TRD NFR-03, TRD NFR-05

**Acceptance criteria:**
- Given any state change (item reported, claim submitted, claim approved/rejected, item returned, item deleted, deletion request), an append-only AuditLog entry is written with actor_id, action, entity_type, entity_id, before, after, created_at.
- Given an audit log entry, no user (including admin) can modify or delete it.
- Given the audit log, it is queryable by actor, action, entity, and date range.

**Definition of done:** All state changes logged immutably; log is queryable; tampering impossible.
