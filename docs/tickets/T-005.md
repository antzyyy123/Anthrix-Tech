# T-005 — Location pin on map

**Depends on:** T-003
**Source:** TRD FR-02, NFR-04

**Acceptance criteria:**
- Given the report form, the location input shows a map with a droppable pin; the pin's lat/lng is stored with the item.
- Given an optional free-text note, it is stored alongside the pin; free text alone is not accepted as the location.
- Given the map on mobile, one-handed pinch/drop interaction works on a cheap Android screen (touch target ≥ 44px).
- Given map load failure, the user can still submit with a free-text location note (graceful degradation).

**Definition of done:** Item stored with lat/lng + optional note; map usable one-handed on mobile; fallback to note-only when map fails.
