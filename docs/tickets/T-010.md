# T-010 — Admin approve/reject claim

**Depends on:** T-009
**Source:** TRD FR-05

**Acceptance criteria:**
- Given a pending claim, admin taps "Approve" → claim status becomes "approved," claimer and reporter notified, item status becomes "claimed."
- Given a pending claim, admin taps "Reject" with notes → claim status becomes "rejected," claimer notified with reason, item unlocked for other claims.
- Given admin action, an audit log entry is written (see T-012) recording actor, action, before/after state.
- Given a claim resolved, it no longer appears in the pending queue.

**Definition of done:** Approve/reject transitions claim and item state; both parties notified; audit entry written.
