# T-008 — Claim item with proof photo

**Depends on:** T-002, T-003, T-007
**Source:** TRD FR-04, PRODUCT-SPEC Flow C

**Acceptance criteria:**
- Given a logged-in user on an item detail page, tapping "Claim" opens the claim form with proof photo upload.
- Given a claim submitted without a proof photo, submission is blocked and the item is not locked.
- Given a valid claim with proof photo, a Claim record is created with status "pending," the item is locked from other claims, and the admin is notified within 5 minutes.
- Given a claim on an item already locked by a pending claim, the claim is rejected with "item already has a pending claim."

**Definition of done:** Claim requires proof photo; item locked during pending claim; admin notified within 5 minutes.
