# T-003 — Report item form

**Depends on:** T-001, T-002
**Source:** TRD FR-02, PRODUCT-SPEC Flow A

**Acceptance criteria:**
- Given a logged-in user on the report page, the form shows: category dropdown, photo upload, location pin, description text, consent checkbox, submit button — max 4 taps to core submission.
- Given valid input, submitting creates an Item record with status "listed" and appears in the feed within 10 seconds.
- Given missing required fields, submission is blocked with inline field errors; no item is created.
- Given the consent checkbox unchecked, submit is disabled.
- Given an invalid category, submission is rejected.

**Definition of done:** A submitted item appears in the feed within 10 seconds; all validation errors display inline.
