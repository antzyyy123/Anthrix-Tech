# T-009 — Admin claim verification queue

**Depends on:** T-008
**Source:** TRD FR-05, PRODUCT-SPEC Flow D

**Acceptance criteria:**
- Given an admin, the queue lists all pending claims with item photo, claimer proof photo, claimer contact, item location, and time submitted.
- Given a claim older than 24 hours, it is flagged as overdue in the queue.
- Given a non-admin user, access to the queue is rejected (403).
- Given the queue, claims are ordered by submission time (oldest first).

**Definition of done:** Admin sees all pending claims with review details; non-admin blocked; overdue claims flagged at 24h.
