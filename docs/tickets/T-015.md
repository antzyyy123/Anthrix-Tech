# T-015 — Deployment & hosting

**Depends on:** T-001 through T-014
**Source:** TRD §1 Overview, TRD NFR-02

**Acceptance criteria:**
- Given the stack selected by Anthrix operations (SQLite single-file or managed Postgres), the app deploys to the chosen host.
- Given environment variables, secrets (DB credentials, email provider keys, map API keys) are injected via env, never committed.
- Given deployment, the app is reachable via the Anthrix domain with HTTPS.
- Given backups, a database backup runs on a defined schedule and can be restored.
- Given the 24-hour admin turnaround commitment, Anthrix operations staff are trained on the admin queue.

**Definition of done:** App deployed on HTTPS; secrets not committed; backups scheduled and restorable; ops staff trained.
