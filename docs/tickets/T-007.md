# T-007 — Item detail view

**Depends on:** T-003, T-005
**Source:** PRODUCT-SPEC Flow B, screen inventory

**Acceptance criteria:**
- Given an item ID, the detail page shows full photo gallery, location on map, full description, status tag.
- Given an item already claimed/returned, the "Claim" button is hidden.
- Given the reporter viewing their own item, edit/delete options are available.
- Given item not found, a 404 page is shown.

**Definition of done:** Item detail renders all fields; claim button visibility follows status; 404 for missing items.
