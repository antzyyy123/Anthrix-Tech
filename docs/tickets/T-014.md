# T-014 — Theme toggle & accessibility

**Depends on:** T-001
**Source:** TRD NFR-04, PRODUCT-SPEC UI requirements

**Acceptance criteria:**
- Given the app, a theme toggle (light/dark) exists; default follows system preference; manual selection persists.
- Given WCAG AA, all text meets contrast minimums; focus states visible; screen-reader labels on icons and buttons.
- Given mobile, touch targets ≥ 44px; app usable one-handed on a cheap Android on mobile data; page load < 3s on 3G.

**Definition of done:** Theme toggle works; WCAG AA contrast met; mobile touch targets and load time verified.
