# T-011 — Mark returned + notifications (in-app + email)

**Depends on:** T-010
**Source:** TRD FR-06, PRODUCT-SPEC Flow E

**Acceptance criteria:**
- Given an approved claim, admin marks item "Returned" → item status becomes "returned."
- Given a return, both reporter and claimer receive an in-app notification and an email notification.
- Given notification failure, the error is logged and the return is still recorded (retry mechanism queued).
- Given a returned item, it is excluded from active search results.

**Definition of done:** Mark-returned transitions item to "returned"; both parties notified in-app + email; failures logged.
