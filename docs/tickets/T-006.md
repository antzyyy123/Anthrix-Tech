# T-006 — Browse & search feed

**Depends on:** T-001, T-003
**Source:** TRD FR-03, PRODUCT-SPEC Flow B

**Acceptance criteria:**
- Given the feed page, items are displayed as cards with thumbnail, category badge, location, date posted, status tag.
- Given a category filter, only items of that category are shown.
- Given a location filter, items near that location are shown.
- Given a date range filter, items posted within the range are shown.
- Given expired items (past 90 days), they are hidden from the feed.
- Given search results, they load in under 2 seconds.

**Definition of done:** Feed displays item cards; category/location/date filters work; expired items hidden; results < 2s.
