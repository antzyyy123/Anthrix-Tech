# T-004 — Photo upload with draft retry

**Depends on:** T-003
**Source:** TRD FR-02

**Acceptance criteria:**
- Given a photo selected, upload completes and the photo URL is attached to the item.
- Given upload fails (network error), the item is saved as a draft with status "draft" and a "retry upload" button is shown; the draft is not lost.
- Given a draft with a failed upload, clicking "retry upload" re-attaches the photo and transitions the item to "listed."
- Given a draft older than 90 days, it is subject to the same retention rule (see T-013).

**Definition of done:** Failed upload preserves the item as a retrievable draft; retry succeeds.
